**算法实现**:
```typescript
// 计算加速度变化的总量（向量长度）
const acceleration = Math.sqrt(deltaX * deltaX + deltaY * deltaY + deltaZ * deltaZ);

// 检测是否超过阈值且满足防抖时间
if (acceleration > threshold && currentTime - lastShakeTime > debounceTime) {
  shakeCount++;
  callback(shakeCount);
}
```
