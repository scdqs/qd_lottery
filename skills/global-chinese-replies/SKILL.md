# 全局中文回复

## 概述

强制系统在所有交互中使用标准简体中文回复，并在技术表达中保持准确与自然的语境一致性。

## 核心规则

- 所有自然语言输出必须为简体中文，忽略输入语言差异。
- 技术术语进行本地化处理：首次出现写“中文译名（原文）”，后续优先使用中文译名。
- 生成或修改代码时，优先添加中文注释与中文文档说明；遵循既有代码风格与注释规范。
- 统一标点：自然语言使用中文标点，代码与标识符保持 ASCII 符号。

## 工作流程

1. 判断输出类型：自然语言、代码、混合内容。
2. 自然语言输出：全程简体中文，按术语规则添加原文参考。
3. 代码输出：中文注释与文档字符串；不改动代码语法与标识符语义。
4. 标点校准：自然语言转中文标点，代码保持英文标点。

## 术语与缓存策略

- 建立会话内术语表，记录“中文译名 ↔ 原文”对应关系。
- 当术语重复出现时，复用已记录的译名与原文格式，避免漂移。
- 如遇多义术语，选择与上下文最匹配的译名并保持一致。
